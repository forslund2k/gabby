# Gabby — AI chat agents for small business

A small-business owner signs up, creates a chat agent (name + plain-English
instructions + knowledge base), and pastes **one `<script>` tag** on their
website. Visitors get instant answers 24/7; the owner watches it all from a
dashboard.

## Quickstart

```bash
cd ~/workspace/gabby
pip install -r requirements.txt
python app.py          # http://localhost:5000
```

The SQLite database (`gabby.db`) is created automatically on first run.

## Environment variables

See `.env.example`. The important one:

| Variable        | Default                    | Purpose                                     |
|-----------------|----------------------------|---------------------------------------------|
| `SECRET_KEY`    | dev key (change in prod!)  | Flask session signing                       |
| `GABBY_API_KEY` | *(empty = demo mode)*      | API key for an OpenAI-compatible chat API   |
| `GABBY_API_BASE`| `https://api.openai.com/v1`| Base URL of the chat completions API        |
| `GABBY_MODEL`   | `gpt-4o-mini`              | Model name for chat completions             |

**Demo mode** (no key set): replies are generated by keyword matching against
the agent's knowledge base — free, offline-friendly, great for testing. The
dashboard and test-chat page show a "DEMO MODE" badge so it's obvious.

## How the chat brain works

1. `POST /api/chat` receives `{public_key, session_token, message}`.
2. The agent's knowledge chunks are ranked by simple keyword overlap with
   the message; the top 3 are used as context.
3. With `GABBY_API_KEY` set, the prompt (instructions + knowledge + last 10
   messages) goes to the configured LLM. Otherwise the demo responder quotes
   the best-matching chunk, or gives a friendly "I don't know that yet" reply.
